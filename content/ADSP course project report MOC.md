# ADSP course project report MOC

這是期末書面報告的工作區。報告要求是 10 頁以上，不含封面，可中英文，格式接近期刊論文或碩博士論文：abstract、sections/subsections、conclusion、IEEE-style references。

可選兩條主題線：

- [[Seismic wave signal processing project]]：以地震波 arrival picking / detection 為主題，能直接連到本課的 [[Short-time Fourier transform]]、[[Matched filter]]、[[Wavelet transform for seismic picking]]、[[STA LTA picker]]、[[AIC picker]]、[[Waveform correlation detector]]。
- [[Hawkes process limit order book project]]：以 Hawkes process modeling of event streams 為主題，連到 [[Probability for random signals]]、[[Hawkes process]]、[[Multivariate Hawkes process]]、[[Marked Hawkes process]]、[[Limit order book events]]。

建議報告章節架構：

1. Abstract：問題、方法類型、比較角度、主要結論。
2. Introduction：為什麼這個題目屬於 ADSP；資料是 waveform 還是 event stream。
3. Background：補必要數學，不要變成教科書。
4. Literature Review：把三篇核心論文按方法比較，而不是逐篇流水帳。
5. Methodology：重建主要 algorithm pipeline。
6. Discussion：優缺點、適用情境、和課程內容的關聯。
7. Conclusion。
8. References：用 IEEE 格式。
