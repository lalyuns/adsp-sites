# Hawkes kernel matrix

Hawkes kernel matrix 的 entry $\phi_{ij}(t)$ 表示 type $j$ 的過去事件對 type $i$ 未來 intensity 的影響。正 kernel 是 excitation；若模型允許負值，可表示 inhibition。
