# Linear algebra for DSP

ADSP 裡的 linear algebra 主要看三件事：matrix-vector multiplication 表示 transform/filter bank，orthogonal basis 表示 energy-preserving coordinates，matrix factorization 表示 fast algorithm 或 dimensionality reduction。

相關入口：[[Matrix multiplication complexity]], [[Orthogonality and inner product]], [[Eigenvalues and eigenvectors]], [[Singular value decomposition]]。
