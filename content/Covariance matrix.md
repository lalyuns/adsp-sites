# Covariance matrix

Covariance matrix 收集多個 random variables 或 signal components 之間的 covariance。若 $X$ 是資料向量，常寫

$$C_X=E[(X-\bar X)(X-\bar X)^T].$$

KLT/PCA 想找一個 transform 讓 transformed covariance matrix 變 diagonal，也就是 components decorrelated。
