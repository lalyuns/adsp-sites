# Covariance matrix

Covariance matrix 的第 $(i,j)$ 項描述兩個 variables 一起變動的程度。KLT/PCA 會找它的 eigenvectors，讓 transformed coefficients decorrelated。

連結：[[Matrix diagonalization for transforms]]、[[Linear algebra for DSP]]。
