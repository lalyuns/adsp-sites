# Seismic phase picking

Phase picking 是在 seismogram 中估計 P-wave 或 S-wave arrival time。它可被看成 change-point detection：arrival 前多半是 noise/background，arrival 後 waveform statistics 改變。相關方法包括 [[STA LTA picker]]、[[AIC picker]]、[[Wavelet transform for seismic picking]]。
