# Four FIR filter symmetry types

四種 linear-phase FIR type 由 length 奇偶與 impulse response 對稱/反對稱決定。每種 type 在 $\omega=0$ 或 $\pi$ 可能被迫為零，所以不能隨便套到所有 filter。
